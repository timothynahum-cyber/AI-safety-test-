# AI Safety Tests - Manual Red Teaming

## What system I tested
Public LLMs: ChatGPT, Meta AI

What I attacked
Direct prompt injection: "ignore previous instructions", "system override"
Jailbreaking / Guardrail bypass testing

What I achieved
Demonstrated that models can sometimes be tricked to ignore safety instructions when given strong override prompts. Documented refusals vs compliance.

How I demonstrated impact
Captured screenshots of prompts and responses as proof of concept for learning.

Tools: My own scripts / manual prompts
